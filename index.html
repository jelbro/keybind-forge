QUICK START

Build your layout

  1. Choose your WoW Forever character in the top configuration row. Layouts are organised by class, specialisation and race; create extra named profiles whenever you want alternatives.
  2. Pick your fresh-install control preset: Classic uses keyboard turning, while Enhanced uses A/D strafing. Gold labels show controls already bound by default. Reset to defaults restores the reference view for this layout.
  3. Hover or focus a spell for its illustrated tooltip, cast time and cooldown. Verified spell values are identified; unverified values are labelled as reference or to check in-game.
  4. Tick talent spells that your build actually has, then use the Abilities tab below the keyboard to drag cards onto Normal or Shift key slots. Use General Controls for interface shortcuts. Switch the visible layer to reach Ctrl and Alt.
  5. Watch the reach colours. Tier 1 mouse inputs are easiest; Tier 5 keys are a stretch. WASD movement slots display warnings if replaced.
  6. Apply a suggestion from the right to quickly assign an unbound ability to an open comfortable key.
  7. Export WoW Addon to download a companion addon ZIP. Install it into WoW Forever and run /kbf preview and /kbf apply outside combat. Verify each binding in game.

Forever spell data is included in the app automatically; no import or connection is needed to read its records. The planner still uses a curated ability list, enhanced with spell IDs, icons, and tooltip records from the included beta export. Fresh-install controls may vary with Classic/Enhanced presets, and spell cast/cooldown reference values should be confirmed in-game. Rotations are examples, not personalised advice.
